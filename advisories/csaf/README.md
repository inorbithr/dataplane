# Security advisories (CSAF 2.0)

Advisories for the agent are published here as [CSAF 2.0](https://docs.oasis-open.org/csaf/csaf/v2.0/csaf-v2.0.html)
documents, one JSON file per advisory, named `<year>/inorbit-<year>-<number>.json`,
alongside the GitHub Security Advisory for the same issue. `provider-metadata.json`
describes this directory to CSAF aggregators.

There are no advisories yet. How vulnerabilities are reported and handled is in
[SECURITY.md](../../SECURITY.md).
